# 上传 GitHub

本包已经整理为源码仓库结构。论文暂定题目为 **Recovering internal parcel boundaries from coarse agricultural annotations**，仓库可命名为 `coarse2boundary`。

## 网页上传

1. 在你自己的 GitHub 账号下新建仓库，选择需要的可见性。本包已有 README、MIT LICENSE 和 `.gitignore`，不必再让 GitHub 生成重复文件。
2. 解压源码包，上传 `coarse2boundary` 文件夹**里面的文件和子文件夹**到仓库根目录。直接上传 ZIP 只会把 ZIP 作为一个文件保存。
3. GitHub 网页每次最多上传 100 个文件。本包超过该数量，可以按子文件夹分几次提交；若提供了网页分批上传包，则按 `01`、`02`、`03` 等目录顺序，每次将其内容拖到同一个仓库根目录。
4. 提交后，检查仓库首页能显示英文 README，并能浏览 `experiments/`、`downstream/`、`tools/` 和 `meta/`。

也可以用 GitHub Desktop 或 Git 一次提交整个源码目录。账号登录由你在 GitHub 或客户端完成，无需把密码或访问令牌发给他人。

[GitHub 官方上传说明](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)

仓库建立后，将仓库地址补入论文摘要的代码可用性说明。论文投稿源文件、数据、权重和个人审阅记录不在此源码包内。
